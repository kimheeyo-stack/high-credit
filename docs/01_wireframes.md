# Figma 와이어프레임 가이드 — 핵심 화면 5장

> Figma에서 그릴 때 이 파일을 참고하세요.
> 아래 ASCII 목업은 구조와 배치 기준이며, 실제 디자인 시 색상·폰트는 자유롭게 적용하세요.
> 모바일 기준 프레임: **390 × 844px (iPhone 14)** 또는 **360 × 800px (Android)**

---

## 화면 1 — 홈 (Home)

**목적:** 학생이 앱을 열었을 때 가장 먼저 보는 화면. 핵심 상태를 한눈에.

```
┌──────────────────────────────────────┐
│  하이학점              김민준 ▾      │  ← 상단 앱바 (이름 탭 → 프로필)
├──────────────────────────────────────┤
│                                      │
│  ┌────────────────────────────────┐  │
│  │  졸업까지 남은 학점            │  │
│  │  ████████████████░░░░  136/192 │  │  ← 프로그레스 바
│  │  앞으로 56학점 더 취득 필요    │  │
│  └────────────────────────────────┘  │
│                                      │
│  ┌──────────────┐ ┌───────────────┐  │
│  │  ⚠️ 미이수    │ │  ✅ 이번학기  │  │  ← 요약 카드 2개
│  │  위험 2과목  │ │  32학점 신청  │  │
│  └──────────────┘ └───────────────┘  │
│                                      │
│  📅 다가오는 일정                    │
│  ─────────────────────────────────── │
│  D-3  수학 지필고사                  │
│  D-7  영어 수행평가 제출 마감        │
│  D-14 2학기 수강신청                 │
│                                      │
│  ┌────────────────┐ ┌─────────────┐  │
│  │  + 성적 입력   │ │  학점 진단  │  │  ← 주요 액션 버튼 2개
│  └────────────────┘ └─────────────┘  │
│                                      │
├──────────────────────────────────────┤
│   홈   │  학점  │  성적  │  진단     │  ← 하단 탭바
└──────────────────────────────────────┘
```

**핵심 컴포넌트:**
- 상단 프로그레스 카드: 136/192 (현재/목표), 진행률 바
- 미이수 위험 카드: 빨간 배경, 과목 수 표시
- 이번 학기 카드: 초록 배경, 신청 학점 표시
- D-Day 목록: 최대 3개, 날짜 가까울수록 위
- CTA 버튼 2개: 성적 입력(주), 학점 진단(보조)

## 화면 2 — 학점 게이지 (Credit Gauge)

**목적:** 192학점을 향한 전체 진행 상황을 교과 영역별로 상세히 보여줌.

```
┌──────────────────────────────────────┐
│  ← 학점 현황                         │
├──────────────────────────────────────┤
│                                      │
│           136 / 192 학점             │  ← 총 취득/목표
│   ┌──────────────────────────────┐   │
│   │  ████████████████░░░░░  71%  │   │  ← 전체 프로그레스 바
│   └──────────────────────────────┘   │
│                                      │
│  [1학년 ▼] [2학년] [3학년]  전체보기 │  ← 학년 필터 탭
│                                      │
│  교과 영역별 취득 현황               │
│  ┌────────────────────────────────┐  │
│  │ 공통과목    ████████████  45/45 │  │  ← 완료: 초록
│  │ 일반선택    █████████░░░  32/40 │  │  ← 진행: 파랑
│  │ 진로선택    █████░░░░░░░  18/30 │  │  ← 부족: 주황
│  │ 융합선택    █████░░░░░░░  16/30 │  │
│  │ 체육·예술   ████████░░░░  16/20 │  │
│  │ 교양        █████████    9/9   │  │  ← 완료: 초록
│  └────────────────────────────────┘  │
│                                      │
│  과목 목록 보기  ›                   │  ← 탭하면 수강 과목 전체 리스트
│                                      │
├──────────────────────────────────────┤
│   홈   │  학점  │  성적  │  진단     │
└──────────────────────────────────────┘
```

**핵심 컴포넌트:**
- 상단 총 학점: 숫자 크게 강조 (136 / 192)
- 전체 프로그레스 바: 71% 표시
- 학년 필터: 탭 선택으로 해당 학년 학점만 필터
- 영역별 바 차트: 각 교과 영역의 취득/목표 학점과 바

## 화면 3 — 성적 입력 (Grade Input)

**목적:** 사용자가 과목별 지필·수행 점수와 출석률을 직접 입력하고 성취율/성취도를 확인.

```
┌──────────────────────────────────────┐
│  ← 성적 입력           2학년 1학기 ▾ │  ← 학기 선택 드롭다운
├──────────────────────────────────────┤
│                                      │
│  과목 추가  [+]         총 32학점    │
│                                      │
│  ┌──────────────────────────────┐    │
│  │  수학 I                4학점 │    │
│  │  출석률  ──────────── 95%    │    │
│  │  지필    ──────────── 70점   │    │
│  │  수행    ──────────── 25점   │    │
│  │  ─────────────────────────── │    │
│  │  성취율  95점 → 성취도 A ✅  │    │  ← 자동 계산
│  └──────────────────────────────┘    │
│                                      │
│  ┌──────────────────────────────┐    │
│  │  영어 독해와 작문      3학점 │    │
│  │  출석률  ──────────── 80%    │    │
│  │  지필    ──────────── 30점   │    │
│  │  수행    ────────────  8점   │    │
│  │  ─────────────────────────── │    │
│  │  성취율  38점 → 성취도 I ⚠️  │    │  ← 미이수 경고 색상
│  └──────────────────────────────┘    │
│                                      │
│             [저장하기]                │
│                                      │
├──────────────────────────────────────┤
│   홈   │  학점  │  성적  │  진단     │
└──────────────────────────────────────┘
```

**핵심 컴포넌트:**
- 학기 선택: 드롭다운 (1학년 1학기 ~ 3학년 2학기)
- 과목 카드: 과목명, 학점, 출석률, 지필점수, 수행점수 입력 필드
- 자동 계산: 지필+수행 합산 → 성취율 → 성취도(A~E/I) 실시간 표시
- 미이수(I) 카드: 빨간 테두리 + 경고 아이콘
- 저장 버튼: 하단 고정

## 화면 4 — 진단 결과 (Diagnosis Result)

**목적:** 현재 학점 상태로 졸업 가능 여부를 자동 진단하고 부족한 부분 안내.

```
┌──────────────────────────────────────┐
│  ← 졸업 진단 결과                    │
├──────────────────────────────────────┤
│                                      │
│  ┌────────────────────────────────┐  │
│  │  ⚡ 주의 필요                  │  │  ← 상태 배너 (초록/주황/빨강)
│  │  미이수 과목 해결이 필요해요.  │  │
│  └────────────────────────────────┘  │
│                                      │
│  체크리스트                          │
│  ──────────────────────────────────  │
│  ✅  공통필수 과목 이수        완료  │
│  ⚠️   총 이수 학점           136/192 │
│  ❌  미이수 과목               2과목 │
│  ✅  창의적 체험활동           완료  │
│  ⚠️   학기당 최소 신청 학점   확인  │
│                                      │
│  부족 분석                           │
│  ──────────────────────────────────  │
│  남은 학점: 56학점                   │
│  남은 학기: 3학기                    │
│  학기당 최소 필요: ≈19학점           │
│  (학기당 최소 신청: 28학점)          │
│                                      │
│  ┌──────────────┐ ┌───────────────┐  │
│  │ 미이수 보기  │ │  학점 시뮬레이터│ │
│  └──────────────┘ └───────────────┘  │
│                                      │
├──────────────────────────────────────┤
│   홈   │  학점  │  성적  │  진단     │
└──────────────────────────────────────┘
```

**핵심 컴포넌트:**
- 상태 배너: 3단계 (✅ 정상 / ⚡ 주의 / 🔴 위험)
- 체크리스트: 졸업 요건 항목별 O/X 표시
- 부족 분석: 남은 학점, 학기, 학기당 필요 학점 계산
- 액션 버튼: 미이수 화면 이동 / 시뮬레이터 이동

## 화면 5 — 미이수 경고 (Warning)

**목적:** 성취율 40% 미만 또는 출석률 2/3 미만인 과목을 명확히 보여주고 조치 방법 안내.

```
┌──────────────────────────────────────┐
│  ← 미이수 경고                        │
├──────────────────────────────────────┤
│                                      │
│  2과목이 미이수 위험 상태입니다       │
│                                      │
│  ┌────────────────────────────────┐  │
│  │  🔴 영어 독해와 작문    3학점  │  │  ← 빨간 카드: 미이수 확정/위험
│  │  ─────────────────────────── │  │
│  │  성취율  38% ━━━━━━━━━━━━━  │  │  ← 40% 선 표시된 바
│  │                   ↑ 기준 40%  │  │
│  │  지금보다 2점 더 필요합니다.  │  │
│  │                               │  │
│  │  [성적 수정하기]               │  │
│  └────────────────────────────────┘  │
│                                      │
│  ┌────────────────────────────────┐  │
│  │  🟡 물리학 I            3학점  │  │  ← 노란 카드: 출석 위험
│  │  ─────────────────────────── │  │
│  │  출석률  62% ━━━━━━━━━━━━━  │  │
│  │                   ↑ 기준 67%  │  │
│  │  앞으로 결석 1회 이내 가능.   │  │
│  │                               │  │
│  │  [출석 수정하기]               │  │
│  └────────────────────────────────┘  │
│                                      │
│  💡 미이수 시 보충이수 대상이 되며,  │
│     보충이수 미완료 시 졸업 유예     │
│     가능성이 있습니다.               │
│                                      │
├──────────────────────────────────────┤
│   홈   │  학점  │  성적  │  진단     │
└──────────────────────────────────────┘
```

**핵심 컴포넌트:**
- 빨간 카드: 성취율 40% 미만 (미이수 확정/위험)
- 노란 카드: 출석률 67% 미만 (이수 불가 위험)
- 각 카드에 "몇 점/몇 회 더 필요" 구체적 수치 표시
- 카드별 수정 버튼: 해당 과목 성적 입력 화면으로 바로 이동
- 하단 안내: 미이수 결과(보충이수, 졸업 유예) 설명
