> 실제 아이들이 앱을 처음 쓸 때 나타날 수 있는 현실적인 반응을 담았습니다.

## 인터뷰 #1 — 학생 A (고1, 14세)

```
날짜: 시뮬레이션   대상: 학생 (고1)

[ 탐색 중 막힌 지점 — 행동 관찰 ]
1. 홈 화면에서 "학점 진단" 버튼을 먼저 눌렀는데
   아무 데이터가 없어서 빈 화면처럼 보여 당황함
2. 성적 입력에서 "과목 추가" 버튼을 누르자
   갑자기 브라우저 팝업창(prompt)이 떠서 멈춤
   — "이게 뭐야?" 하고 입력창을 그냥 닫아버림
3. '교과 영역' 선택에서 번호를 입력하라는 prompt가 뜨는데
   "진로선택이 몇 번이더라?" 하고 스크롤을 올려봄

[ 질문별 답변 요약 ]
A-2 (입력 막힌 곳):
  "과목 추가할 때 팝업창이 갑자기 뜨는 게 낯설었어요.
   앱이 아니라 컴퓨터 알림창 같아서 그냥 닫았어요."

A-3 (교과 영역 이해):
  "수학이 일반선택인지 공통과목인지 헷갈려요.
   학교에서 그냥 '수학'이라고 하지 영역은 잘 안 알려줘서요."

A-4 (출석 숫자 알고 있었나):
  "총 수업 횟수요? 그거 몰라요. 몇 번 결석했는지는
   알아도 총 몇 번인지는 선생님한테 물어봐야 할 것 같아요."

A-5 (경고 화면 이해):
  "2점 더 필요하다는 건 알았어요. 근데 지필인지
   수행인지 어디서 2점 올려야 하는지는 몰랐어요."

A-7 (최우선 개선점):
  "과목 추가할 때 팝업 말고 그냥 화면 안에서
   입력하면 좋겠어요."

[ 인상적인 발언 ]
"미이수되면 졸업 못 할 수도 있다는 게 진짜예요?
 그거 몰랐는데 이 앱 보고 알았어요."

[ 종합 ]
YES / NO / **수정 후 가능**
이유: 핵심 내용은 이해했으나 과목 추가 UX(prompt 팝업)가
      치명적 장벽. 수정하면 바로 쓸 수 있을 것 같음.
```

## 인터뷰 #2 — 학생 B (고2, 15세)

```
날짜: 시뮬레이션   대상: 학생 (고2)

[ 탐색 중 막힌 지점 — 행동 관찰 ]
1. 기존 등록된 샘플 과목(수학 I, 영어 독해 등)을 보고
   "이거 우리 학교 과목이랑 달라요"라며 전부 삭제 시도
   → 삭제 확인 창이 없어 한 번에 여러 과목 삭제해버림
2. 점수 입력 칸이 너무 작아서 (모바일 기준) 숫자를
   잘못 입력하고 수정하는 데 시간이 걸림
3. 졸업 진단에서 "56학점 더 필요"를 보고
   "이번 학기에 몇 학점 들으면 돼요?"를 바로 물음
   → 화면에 "약 19학점 이상"은 있었지만 눈에 잘 안 띔

[ 질문별 답변 요약 ]
A-2 (입력 막힌 곳):
  "점수 입력하는 칸이 너무 작아요. 폰으로 하면
   자꾸 옆 칸을 눌러버려요."

A-3 (교과 영역 이해):
  "저는 학교 안내문 보면서 하면 될 것 같아요.
   어차피 학기 초에 한 번만 입력하면 되잖아요."
  (고2는 1년 경험 있어서 용어에 좀 더 익숙)

A-4 (출석 숫자 알고 있었나):
  "출석률은 학교 앱에서 볼 수 있어요. 근데 총
   수업 횟수는 거기도 안 나와요. % 로 입력하면
   안 돼요?"

A-5 (경고 화면 이해):
  "영어 독해 38점짜리가 2점 더 필요하다는 거
   바로 이해됐어요. 이건 진짜 유용한 것 같아요."

A-7 (최우선 개선점):
  "입력 칸 크기랑, 출석을 % 로 입력하는 거요."

[ 인상적인 발언 ]
"학기말에 갑자기 미이수될 것 같을 때 진짜 유용하겠다.
 이런 거 학교에서 만들어줘야 하는 거 아닌가요?"

[ 종합 ]
**수정 후 가능**
이유: 핵심 기능 이해도 높음. 모바일 입력 UX(칸 크기,
      출석 % 입력)와 삭제 확인 창만 수정하면 바로 적용 가능.
```

## 인터뷰 #3 — 학부모 A (고1 자녀 어머니)

```
날짜: 시뮬레이션   대상: 학부모 (고1 자녀)

[ 탐색 중 막힌 지점 — 행동 관찰 ]
1. 홈 화면의 "학점 진단" 버튼을 바로 눌렀는데
   데이터가 없어서 진단 결과가 '공란'처럼 보임
   → "이게 작동이 되는 건가요?" 라고 물음
2. 자녀 과목을 직접 입력하려 했는데
   지필/수행 구분을 몰라서 멈춤
   ("성적표에는 그냥 합산점수만 나오는데요")
3. "교과 영역"이 뭔지 몰라 인터넷 검색하려 했음

[ 질문별 답변 요약 ]
B-1 (입력 번거로움):
  "과목 하나 입력하는 데 팝업창이 4번 뜨는 게
   너무 번거로워요. 한 화면에서 다 입력하게 해주세요."

B-2 (경고→조치 연결):
  "2점 더 필요하다는 건 알겠는데, 기말 지필에서
   2점인지, 수행에서 2점인지가 안 나와 있어요.
   담임 선생님께 여쭤봐야 하나요?"

B-3 (진단 화면 가독성):
  "주의 / 위험 배너는 한눈에 보였어요.
   그런데 체크리스트 항목이 작아서 잘 안 읽혀요."

B-4 (영역별 현황):
  "'진로선택 18/30' 이런 게 뜨는데, 우리 아이가
   진로선택을 더 들어야 한다는 건 알겠어요.
   어떤 과목을 들어야 하는지는 안 나오죠?"

B-5 (자녀 자립 사용):
  "솔직히 처음엔 같이 입력해줘야 할 것 같아요.
   한 번만 제대로 설명해주면 혼자 할 수 있을 것 같고요."

B-6 (최우선 개선점):
  "과목 추가를 팝업 없이 화면 안에서 하는 것,
   그리고 지필/수행 합산 점수로만 입력해도 되게끔."

[ 인상적인 발언 ]
"학교에서는 '미이수'라는 단어를 잘 안 쓰고
 애들도 몰라요. 이 앱이 그걸 눈앞에 보여준다는 게
 제일 가치 있는 것 같아요."

[ 종합 ]
**수정 후 가능**
이유: 진단·경고 가치는 충분히 인식. 과목 추가 UX와
      점수 입력 방식(합산 입력 옵션)만 해결되면
      자녀와 함께 바로 활용 가능.
```

## 인터뷰 #4 — 학부모 B (고2 자녀 아버지)

```
날짜: 시뮬레이션   대상: 학부모 (고2 자녀)

[ 탐색 중 막힌 지점 — 행동 관찰 ]
1. 처음에 스마트폰으로 index.html을 열었는데
   화면이 작게 나옴 (390px 고정 레이아웃이 폰 전체에 안 맞음)
2. 하단 탭 "학점현황" 눌렀다가 다시 "학점진단"으로 가려 했는데
   뒤로가기 버튼을 눌러 브라우저가 꺼져버림
3. 과목 삭제 후 "저장하기"를 누르지 않아도 되는 건지 헷갈렸음

[ 질문별 답변 요약 ]
B-1 (입력 번거로움):
  "입력 자체는 어렵지 않아요. 점수를 알면
   10분이면 다 넣을 것 같아요."

B-2 (경고→조치 연결):
  "경고 뜨면 성적 수정하러 가는 버튼이 있는데
   실제로 성적을 올리는 건 시험을 잘 봐야 하는
   거잖아요. 앱이 그걸 해줄 순 없으니까 경고만
   빨리 알려주면 충분한 것 같아요."

B-3 (진단 화면 가독성):
  "'주의' 배너가 주황색인데 빨간 게 아니라서
   처음에 별로 안 심각한 줄 알았어요.
   미이수 있으면 좀 더 강하게 표시됐으면 해요."

B-5 (자녀 자립 사용):
  "고2 애한테는 그냥 줘도 할 것 같아요.
   학기 초에 과목 입력만 도와주면요."

B-6 (최우선 개선점):
  "브라우저 뒤로가기 눌렀을 때 앱이 꺼지는 거요.
   이게 제일 불편했어요."

[ 인상적인 발언 ]
"192학점 중 지금 몇 학점인지 한눈에 보인다는 게
 좋아요. 저도 오늘 처음 알았거든요, 그 숫자를."

[ 종합 ]
**수정 후 가능**
이유: 기능 이해도 양호. 브라우저 뒤로가기 대응과
      경고 강도 표현만 보완하면 바로 적용 가능.
```

## 공통 발견 사항 요약

| 문제 | 발견 횟수 | 심각도 |
|------|-----------|--------|
| 과목 추가 시 `prompt()` 팝업 UX | 4명 전원 | 🔴 치명적 |
| 총 수업 횟수 모름 (% 입력 원함) | 3명 | 🔴 치명적 |
| 교과 영역(카테고리) 용어 혼란 | 3명 | 🟠 높음 |
| 모바일 입력 칸 너무 작음 | 2명 | 🟠 높음 |
| 브라우저 뒤로가기 시 앱 종료 | 1명 | 🟠 높음 |
| 지필/수행 합산 입력 옵션 요청 | 2명 | 🟡 보통 |
| 과목 삭제 확인 창 없음 | 1명 | 🟡 보통 |
| 미이수 경고 강도 표현 약함 | 1명 | 🟡 보통 |
| 데이터 없을 때 빈 화면 (온보딩 없음) | 2명 | 🟡 보통 |
