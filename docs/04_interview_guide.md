# 사용자 테스트 가이드 — 하이학점 (자녀 적용용)

> **목적:** 자녀들이 앱을 혼자서 편하게 쓸 수 있는지(UX), 학점 계산이 정확한지(기능) 확인한다.
> **대상:** 자녀 (학생) + 부모 본인 (학부모 시점)
> **시간:** 1인당 15~20분
> **방법:** `prototype/index.html`을 자녀 기기에 열어두고 직접 조작하게 한다.

---

## 진행 원칙
- 설명 없이 건넨다. "그냥 한번 써봐" 한 마디만.
- 막히는 곳을 메모한다. 그게 고칠 부분이다.
- 유도 질문 금지. "어렵지?" 말고 "어때?"

---

## 파트 A — 학생 질문지

### 1. 프로토타입 탐색 (5분) — 먼저 자유롭게

기기를 건네고 조용히 관찰한다. 아래를 메모:
- 어느 버튼을 제일 먼저 누르는가
- 어디서 멈추거나 헷갈려하는가
- 뭔가 잘못 입력하거나 되돌아가는 지점

---

### 2. 탐색 후 질문 (10분)

| # | 질문 | 확인하려는 것 |
|---|------|---------------|
| A-1 | "이 앱이 뭘 해주는 건지 한 마디로 말해봐." | 핵심 기능이 전달됐는지 |
| A-2 | "성적 입력하다가 막히거나 헷갈린 부분 있어?" | 입력 UX 문제 |
| A-3 | "'교과 영역' 선택할 때 내 과목이 어디 해당하는지 바로 알 수 있었어?" | 카테고리 용어 이해도 |
| A-4 | "'출석 횟수 / 총 수업 횟수' 넣을 때, 그 숫자를 바로 알고 있어?" | 입력 데이터 접근성 |
| A-5 | "미이수 위험 경고 화면 봤어? 거기서 뭘 해야 할지 바로 이해됐어?" | 경고 화면 명확성 |
| A-6 | "이걸 학기 시작할 때부터 쓰면 도움이 될 것 같아?" | 실사용 의향 |
| A-7 | "딱 한 가지만 고치면 훨씬 편할 것 같다, 그게 뭐야?" | 최우선 개선점 |

---

## 파트 B — 학부모 시점 질문지

> 부모 본인이 직접 앱을 써보면서 "내 아이 학점을 관리하는 도구"로서 점검한다.

### 1. 직접 입력 테스트 (5분)

자녀의 실제 과목 하나를 골라 직접 입력해본다.
(예: 현재 학기 수학 과목 — 출석 횟수, 지필, 수행 점수)

---

### 2. 탐색 후 질문 (10분)

| # | 질문 | 확인하려는 것 |
|---|------|---------------|
| B-1 | "성적 입력이 얼마나 걸렸어요? 번거롭지 않았나요?" | 입력 부담 |
| B-2 | "'미이수 위험' 경고가 뜰 때 어떤 행동을 취해야 하는지 바로 알 수 있었나요?" | 경고 → 조치 연결성 |
| B-3 | "졸업 진단 결과 화면에서 '지금 우리 아이 상황이 어떻다'는 게 한눈에 보였나요?" | 진단 화면 가독성 |
| B-4 | "학점 현황 화면에서 어떤 영역이 부족한지 바로 파악됐나요?" | 영역별 현황 명확성 |
| B-5 | "아이 혼자 이 앱을 매 학기 업데이트하게 할 수 있을 것 같나요?" | 자녀 자립 사용 가능성 |
| B-6 | "이 앱에서 지금 당장 고쳐야 할 것 같은 부분이 있다면요?" | 최우선 개선점 |
