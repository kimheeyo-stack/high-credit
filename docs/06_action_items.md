# 최종 기능 판정 및 조치 사항

---

## 통과 기준 판정표

| 지표 | 기준 | 결과 | 판정 |
|------|------|------|------|
| "앱이 뭘 해주는지" 정확히 설명 | 2명 이상 | **4명 전원** | ✅ 통과 |
| 설명 없이 성적 입력 완료 | 2명 이상 | **2명** (나머지 2명은 prompt에서 멈춤) | ⚠️ 조건부 |
| 미이수 경고 화면 스스로 도달 | 2명 이상 | **3명** | ✅ 통과 |
| 치명적 입력 오류 (잘못된 계산) | 0건 | **0건** | ✅ 통과 |
| "지금 바로 쓸 수 있다" | 과반수 | **0명** (전원 "수정 후 가능") | ⚠️ 조건부 |

> **종합 판정: 수정 후 적용 가능**
> 계산 로직 자체는 정확하나, 입력 UX 2개 문제가 해결되어야 자녀에게 바로 쓸 수 있다.

## 보완 조치 사항

### 🔴 즉시 수정 (이것만 해도 바로 사용 가능)

#### 조치 1 — 과목 추가 UI: `prompt()` → 인라인 폼으로 교체
- **문제:** 과목 추가 버튼 누르면 브라우저 팝업(prompt)이 4번 연속으로 떠서 앱처럼 느껴지지 않음. 전원이 불편하다고 언급.
- **해결:** 버튼 클릭 시 카드 형태의 입력 폼이 화면 안에서 펼쳐지도록 교체.
- **변경 전:** `prompt('과목명을 입력하세요:')`
- **변경 후:** 과목명, 학점, 카테고리, 수업 횟수를 한 화면 인라인 폼으로 입력

#### 조치 2 — 출석 입력: 횟수 입력 → % 직접 입력 옵션 추가
- **문제:** "총 수업 횟수"는 학생도 부모도 바로 알 수 없음. 학교 포털에서도 제공 안 되는 경우가 많음.
- **해결:** 출석률(%)을 직접 입력하면 내부에서 역산하는 방식으로 변경.
- **변경 전:** `출석 횟수 [   ] / 총 수업 횟수 [   ]`
- **변경 후:** `출석률 [   ] %` 단일 입력 (내부 로직: `attendedClasses = totalClasses * rate`)

### 🟠 다음 버전에서 수정 (우선순위 높음)

#### 조치 3 — 교과 영역 선택에 과목 예시 힌트 추가
- **문제:** 카테고리 이름(일반선택, 진로선택 등)이 낯설어 선택을 주저함.
- **해결:** 각 영역 옆에 대표 과목 예시 표기.
  - 예: `일반선택 (수학I, 영어, 물리학I 등)`, `공통과목 (국어, 수학, 한국사 등)`

#### 조치 4 — 브라우저 뒤로가기 대응
- **문제:** 하단 탭 앱인데 브라우저 뒤로가기를 누르면 앱 자체가 꺼짐.
- **해결:** `history.pushState()`로 화면 전환 이력을 관리하거나, 뒤로가기 이벤트 가로채기.
  ```javascript
  window.addEventListener('popstate', (e) => {
    e.preventDefault();
    switchScreen('screen-home');
  });
  ```

#### 조치 5 — 데이터 없을 때 온보딩 안내
- **문제:** 처음 앱을 열면 진단/현황 화면이 텅 빈 상태로 보여 작동 여부가 불분명함.
- **해결:** 데이터가 0개일 때 "성적을 먼저 입력해주세요 →" 안내 배너 표시.

#### 조치 6 — 과목 삭제 확인 창 추가
- **문제:** 실수로 과목을 삭제해도 복구 불가.
- **해결:** 삭제 전 확인 바텀시트 또는 토스트(`"실행 취소"` 버튼 포함).
