## 1. 서비스 개요

| 항목 | 내용 |
|------|------|
| 서비스명 | 하이학점 (High-Credit) |
| 대상 | 고등학생 (1차 MVP), 학부모 (후순위) |
| 핵심 가치 | 복잡한 고교학점제를 자동으로 계산·경고해 주는 모바일 비서 |

## 4. 데이터 모델 요약

```
AppState (hc_app_state_v1)
├── user: UserProfile
│   ├── id: string (uuid)
│   ├── name: string
│   ├── grade: 1 | 2 | 3
│   └── semester: 1 | 2
├── subjects: SubjectInput[]
│   ├── id, name, credits, category
│   ├── grade, semester
│   ├── totalClasses, attendedClasses
│   ├── writtenScore, performanceScore
│   └── isWrittenExempt (체육 등 지필 없는 과목)
├── events: AppEvent[]
│   ├── id, title, date (ISO 8601)
│   └── type: 'exam' | 'performance' | 'enrollment' | 'other'
├── lastSaved: string (ISO datetime)
└── schemaVersion: 'v1'
```

## 5. 핵심 계산 규칙 (변경 금지 — 정책 기반)

| 규칙 | 값 | 비고 |
|------|-----|------|
| 졸업 기준 학점 | **192** | 6학기 누적 |
| 이수 조건 1: 출석률 | **≥ 2/3 (≈66.7%)** | 출석 횟수/총 수업 횟수 |
| 이수 조건 2: 성취율 | **≥ 40점** | 지필+수행 합산 |
| 학기당 최소 신청 | **28학점** | 미달 시 경고만 (강제 차단 X) |
| 성취도 A 기준 | ≥ 90점 | |
| 성취도 B 기준 | ≥ 80점 | |
| 성취도 C 기준 | ≥ 70점 | |
| 성취도 D 기준 | ≥ 60점 | |
| 성취도 E 기준 | ≥ 40점 | |
| 성취도 I (미이수) | < 40점 | |

> 이 값들은 코드 내 상수 파일(`creditRules`)에 한 곳에만 정의합니다.
> 절대로 UI 파일이나 계산 로직 파일에 하드코딩하지 않습니다.

## 6. 에러 케이스 처리

| 에러 상황 | 처리 방식 |
|-----------|-----------|
| LocalStorage 저장 공간 부족 | 토스트 알림: "저장 공간이 부족합니다. 오래된 데이터를 정리해 주세요." |
| 비공개 모드 (localStorage 차단) | 배너 알림: "비공개 모드에서는 데이터가 저장되지 않습니다." |
| 출석 횟수 > 총 수업 횟수 | 인라인 오류: "출석 횟수는 총 수업 횟수를 초과할 수 없습니다." |
| 지필+수행 > 100점 | 인라인 오류: "지필+수행 합계는 100점을 초과할 수 없습니다." |
| 스키마 버전 불일치 | 경고 다이얼로그 후 데이터 재초기화 |
| 과목명 중복 (같은 학기) | 인라인 오류: "이미 등록된 과목명입니다." |
